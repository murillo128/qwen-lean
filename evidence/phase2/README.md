# Phase 2 evidence

`manifest.json` is the compact full-corpus extraction, contamination, split, and
token-length report generated from the local Phase 2 artifacts.
`verification.json` records the deterministic 24/12/12 reconstruction sample and
the controlled invalid-proof checks.

The full JSONL corpus, external checkouts, LeanDojo trace, tokenizer cache, and
bulky logs remain outside Git and are not published. The root README documents
the frozen commands that regenerate and load the local corpus.
